## 1. Overview

From the block `documentation.doxygen` of Solution.json the module creates **one target** (default
`docs`) that runs Doxygen with the **project's own Doxyfile**. The Doxyfile is passed unchanged;
the working directory is the project root (`CMAKE_SOURCE_DIR`), so its relative paths apply
exactly as with `doxygen <doxyfile>` run from the root.

| Property | Value |
|----------|-------|
| Part of `ALL` | no — `cmake --build <build> --target docs` |
| Doxygen exit code | passed through (`WARN_AS_ERROR = YES` in the Doxyfile makes the target fail) |
| Doxygen missing | W202 at configure time; the target exists and fails with a message when built |
| Without the block | no `find_package(Doxygen)`, no target |
| Target property | `CRAFT_DOXYFILE` (path as in Solution.json), `FOLDER` = `Documentation` |

### Position in the Flow

`CMakeCraft.cmake` includes the module as phase 12 — after packages, before the tests. It needs
no other targets.

## 3. API Reference

### 3.1 _create_doxygen_target()

```cmake
_create_doxygen_target(<DOXYGEN_JSON>)
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `DOXYGEN_JSON` | String | ✓ | JSON string of `documentation.doxygen` |

Checks the fields, searches for Doxygen and creates the target (`add_custom_target` without `ALL`,
`WORKING_DIRECTORY ${CMAKE_SOURCE_DIR}`, `USES_TERMINAL`). The Doxygen version found appears in
the debug output (`[Documentation] Target 'docs': Doxygen 1.12.0 (…)`).

### 3.2 Pipeline on Include

On `include()` the module reads `documentation` from `SOLUTION_JSON`. If the block is missing,
nothing happens. If `documentation.doxygen` is an object, `_create_doxygen_target()` is called.

## 4. JSON Mapping

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| `doxyfile` | ✓ | — | Path of the Doxyfile relative to the project root (absolute is allowed) |
| `target` | — | `docs` | Name of the target |

A configuration generated by CMakeCraft ([Future_Enhancements.md](../../../konzepte/Future_Enhancements.md)
§8.3) does not exist; without `doxyfile` configuring aborts with E001.

---

## 5. Error Handling

| Code | Condition |
|------|-----------|
| E001 | `doxyfile` missing or empty; `documentation` or `documentation.doxygen` is not an object |
| E102 | A target with the name from `target` already exists |
| E107 | The Doxyfile does not exist (or is a folder) |
| W202 | Doxygen not found |
